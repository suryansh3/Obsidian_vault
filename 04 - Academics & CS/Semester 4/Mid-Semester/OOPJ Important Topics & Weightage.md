## 🔥 **Most Repeated Questions by Topic**

### **1. Class & Object**
- **Static Keyword**: "Explain significance of static variables with example" *(2025, 2024, 2023)*
- **Array Programs**: "Swap first-last array elements" *(2025 Mid 2, 2024)*
- **Mixed Input**: "Accept numbers from Scanner + Command Line, find largest/repeated" *(2025 Mid 2, 2024)*

### **2. Inheritance & Polymorphism**
- **Dynamic Method Dispatch**: "Create Bank class with ROI, implement in HDFC/ICICI using DMD" *(2025 Mid 2, 2025 Mid, 2024)*
- **Abstract Class**: "Create abstract class Shape with area(), implement Circle & Square" *(2025, 2024)*
- **Theory**: "Difference between method overloading & overriding" *(2024, 2023)*

### **3. Interfaces**
- **Bank Interface**: "Create interface Calculate with Interest(), implement in SBI/HDFC" *(2025 Mid 2)*
- **Payment Interface**: "Interface Payment with processPayment(), implement in CreditCard & PayPal" *(2025 End Sem)*
- **Multiple Inheritance**: "Show multiple inheritance using interfaces Flyable & Swimmable" *(2025 Mid)*

### **4. Exception Handling**
- **Custom Exception**: "InvalidRollNumberException for negative roll no" *(2025 End Sem)*
- **Even-Odd Count Exception**: "Throw InvalidSetException if even count ≠ odd count" *(2024 Mid)*
- **Checked vs Unchecked**: "Differentiate with examples" *(2025 Mid 2, 2025 End Sem)*

### **5. Packages & Inner Classes**
- **Package Creation**: "Create package Department with Student class" *(2025 Mid)*
- **Inner Class**: "Student class with inner class Exam for marks" *(2025 Mid)*
- **Static Nested Class**: "Calculator with nested MathOperations class" *(2025 End Sem)*
