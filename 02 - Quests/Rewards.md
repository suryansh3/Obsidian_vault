# 🎁 Gacha Rewards

Earn XP on the [[Home|dashboard]] -> every `roll_cost_xp` XP unlocks one roll (see [[Quest Config]]). The roll picks from this table by **weight** (higher = more likely) and logs the loot in today's daily note.

| Tier | Feel |
| --- | --- |
| Common | small treats, frequent |
| Rare | proper breaks |
| Epic | something you look forward to all week |
| Legendary | rare milestone reward |

Edit the `rewards` list in the properties to make it yours. Pair it with the [[Dopamine Menu]].
