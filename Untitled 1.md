## 🏗️ **1. RESEARCH MANUSCRIPT STRUCTURE**

### **Complete Section Sequence:**
```plaintext
1. TITLE
2. ABSTRACT & KEYWORDS
3. INTRODUCTION
4. LITERATURE REVIEW
5. METHODOLOGY
6. RESULTS
7. DISCUSSION
8. CONCLUSIONS
9. REFERENCES
10. APPENDICES
```

### **IMRaD Framework (Core Structure):**
```
I - Introduction (What & Why)
M - Methodology (How)
R - Results (What found)
a - and
D - Discussion (So what)
```

**🎯 Mnemonic**: **"The Amazing Literature Makes Research Deeply Clear"**

## 🔗 **3. REFERENCING & CITATIONS**

### **Major Styles Comparison:**
| Style | Field | In-text Example | Reference Format |
|-------|-------|----------------|------------------|
| **APA** | Social Sciences | (Smith, 2020) | Author, A. (Year). *Title*. Publisher. |
| **MLA** | Humanities | (Smith 45) | Author, Anna. *Title*. Publisher, 2020. |
| **IEEE** | Engineering | [1] | [1] A. Smith, *Title*. Publisher, 2020. |
| **Chicago** | Various | Smith (2020) | Smith, Anna. 2020. *Title*. Publisher. |

### **Citation Rules - DOs & DON'Ts:**
```plaintext
✅ DO:
- Cite all referenced works
- Use et al. for 3+ authors after first mention
- Arrange multiple citations alphabetically
- Include page numbers for direct quotes

❌ DON'T:
- Use "above/below" for tables/figures
- Start sentences with abbreviations
- Mix citation styles
```

**🎯 Memory Aid**: **"Cite Right, Write Bright"**

## 📊 **4. LITERATURE REVIEW TYPES**

### **Three Organizational Approaches:**
| Type | Focus | Best For |
|------|-------|----------|
| **Chronological** | Time periods, evolution | Historical development |
| **Thematic** | Topics/themes | Multiple perspectives |
| **Methodological** | Research methods | Comparing approaches |

### **Literature Review Process:**
```plaintext
Phase 1: Read abstracts → Judge relevance
Phase 2: Read full papers → Critical analysis
Phase 3: Identify patterns → Research gaps
Phase 4: Formulate questions → Set objectives
```

**💡 Key Sources:**
- Journals, conference proceedings, theses
- Databases: Scopus, Web of Science, Google Scholar
- Library portals: J-Gate, CrossRef

## 🔬 **5. METHODOLOGY & EXPERIMENTS**

### **Method vs Tool vs Technique:**
| Level | Example 1 | Example 2 |
|-------|-----------|-----------|
| **Method** | Simulation | Questionnaire survey |
| **Tool** | Discrete-event simulation | Questionnaire |
| **Technique** | Random-number generation | Hypothesis testing |

### **Experimental Principles:**
```plaintext
1. Randomization - Eliminate bias
2. Replication - Assess variability  
3. Blocking - Control nuisance variables
```

### **Statistical Analysis Tools:**
- **Descriptive**: Mean, median, mode, SD, range
- **Inferential**: t-test, ANOVA, regression
- **Validation**: Internal consistency, external matching

**🎯 Mnemonic**: **"Random Replication Blocks Errors"**

## 📈 **6. TABLES & FIGURES**

### **Presentation Rules:**
| Element | Tables | Figures |
|---------|--------|---------|
| **Title Position** | Above table | Below figure |
| **Numbering** | Table 1.1 | Figure 2.1 |
| **Reference in Text** | "Table 1 shows..." | "(Fig. 2)" |
| **Footnotes** | Source → General → Specific → Probability | Legend & source |

### **When to Use:**
```plaintext
TABLES:
✓ Raw/processed data
✓ Precision values
✓ Multiple comparisons

FIGURES:
✓ Overall trends
✓ Story comprehension  
✓ Multiple element comparison
```

**💡 Pro Tip**: Maximize data-ink ratio in graphs

## 🧮 **7. MATHEMATICAL NOTATION & SI UNITS**

### **Mathematical Writing Rules:**
```plaintext
SYMBOLS:
- Variables: italic (x, y)
- Greek letters: upright (α, β)
- Functions: Roman (log, sin, max)
- Spaces around operators: z = x + y

EQUATIONS:
- Number sequentially
- Explain terms after equation
- Break before operators
```

### **SI Units Quick Guide:**
| Rule | Example ✅ | Example ❌ |
|------|------------|------------|
| Space between number & unit | 25 kg | 25kg |
| No plural for symbols | 10 kg | 10 kgs |
| Derived units with · or / | m/s or m·s⁻¹ | mps |
| °C with space | 25 °C | 25°C |

### **Base SI Units (Flashcards):**
```plaintext
Front: Length | Back: meter (m)
Front: Mass | Back: kilogram (kg) 
Front: Time | Back: second (s)
Front: Current | Back: ampere (A)
Front: Temperature | Back: kelvin (K)
Front: Substance | Back: mole (mol)
Front: Light | Back: candela (cd)
```

**🎯 Mnemonic**: **"My King Henry Doesn't Usually Drink Chocolate Milk"**

## 🤖 **8. AI WRITING TOOLS - ETHICS & USE**

### **Assistive vs Generative AI:**
| Aspect | Assistive AI | Generative AI |
|--------|--------------|---------------|
| **Purpose** | Improves existing text | Creates new content |
| **Examples** | Grammarly, Hemingway | ChatGPT, GPT-4 |
| **Best For** | Grammar, style, tone | Drafts, summaries, ideas |

### **Ethical Guidelines:**
```plaintext
✅ PERMITTED:
- Brainstorming ideas
- Improving language
- Creating outlines
- Summarizing texts

❌ PROHIBITED:  
- Submitting AI-generated text as own
- Using without disclosure
- Sharing confidential data
- Bypassing critical thinking
```

### **Citation Format for AI:**
```plaintext
OpenAI. (2023). ChatGPT (Mar 14 version) [Large language model].
https://chat.openai.com/chat
```

**💡 Key Rule**: AI cannot be an author; researcher owns responsibility

## 📝 **9. TITLE, ABSTRACT & KEYWORDS**

### **Title Guidelines:**
```plaintext
- 10-15 words maximum
- No formulas/abbreviations
- Noun phrase, statement, or question
- Capitalize first and last words
```

### **Abstract Types:**
| Type | Length | Content |
|------|--------|---------|
| **Descriptive** | 3-5 sentences | Problem & method only |
| **Informative** | 1 paragraph | Full summary: problem, method, results, conclusion |
| **Structured** | Multiple paragraphs | Headed sections |

### **Keywords:**
- 3-5 terms maximum
- Reflect core concepts
- Enable database searching

**🎯 Abstract Checklist**: **P-M-R-C**
- Problem
- Method  
- Results
- Conclusion

## ⚠️ **10. COPYRIGHT & PLAGIARISM**

### **Key Differences:**
| Aspect | Copyright | Plagiarism |
|--------|-----------|------------|
| **Nature** | Legal right | Ethical breach |
| **Protects** | Exact expressions | Ideas and content |
| **Penalty** | Legal action | Institutional discipline |

### **Fair Use Principles:**
```plaintext
1. Purpose: Educational, research, criticism
2. Nature: Facts vs creative work
3. Amount: Small portions
4. Effect: No impact on original value
```

**💡 Remember**: Always cite sources; get permission for reuse

## 📋 **12. PRACTICAL TEMPLATES**


### **Basic Reference Formats:**
```plaintext

WEB: Author, A. (Year). Title. URL (Accessed Date).
```
