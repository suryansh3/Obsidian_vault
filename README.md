# Obsidian Vault - Second Brain & Life Dashboard

Personal knowledge base + gamified life system, synced with the Obsidian Git plugin.

| Folder | Purpose |
| --- | --- |
| `00 - Dashboard` | `Home` (opens at launch), `MOC`, `Vault Guide` |
| `01 - Journal` | daily / weekly / monthly / quarterly / yearly notes (Time Garden + Journals plugin) |
| `02 - Quests` | RPG engine: quest config, character, rewards, stat areas, pursuits |
| `03 - AI & ML` | learning roadmap |
| `04 - Academics & CS` | semesters → courses → notes, plus projects |
| `05 - Second Brain & Knowledge` | clippings, drawings, handwritten notes, reference |
| `06 Templates` | Time Garden templates & scripts (plugin-owned) |
| `07 - Archives` · `08 - Resources` · `99 - Meta` | archive, PDFs/guides, attachments & plugin data |

Start at [00 - Dashboard/Vault Guide.md](<00 - Dashboard/Vault Guide.md>). The previous README (an Obsidian + Git sync tutorial) lives in `08 - Resources/Obsidian Git Sync Guide.md`.
