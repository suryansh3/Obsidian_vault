# Operating system

Operating system is the intermediary between the hardware and the user. It acts as the *resource allocator* and *control program*.

Os acts as a -
1. **Referee** - Manage protection,isolation and communication

2. **Illusionist** - Provide clean, easy to use abstraction of physical resources.
    - infinite memory, dedicated machine
    - higher level objects; files, user and messages
    - Masking limitation, virtualisation
    

3. **Glue** - 
   - common services 
   - storage, windows system and networking
   - sharing and authorisation
   - the UI and UX that is the look and the feel.
